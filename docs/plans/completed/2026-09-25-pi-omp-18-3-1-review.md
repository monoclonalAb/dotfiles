## Decisions

- Source-only fix. The user chooses when to `/reload`; existing startup behavior
  then owns any reviewed upgrade and quota-consuming selected-model probe.
- Claude Code 2.1.280 / SDK 0.112.1, OAuth agent/utility betas, TLS/header shape,
  identity/bootstrap, CCH, tool prefix and output cap are unchanged. No transport
  behavior change is needed for the bridge's existing request path.
- New upstream slow-mode hooks, fallback-credit redemption and catalog fallback
  targets are not enabled. Pi retains its own serializer/catalog/parser; upstream
  Opus 5.5 forced-tool-choice and output-fitting catalog changes are not imported.
  Compaction/user profiles remain out of scope.
- The token command, OAuth provider, key cascade and selector are unchanged.
  Auth storage now supports live policy/store replacement and logs credential
  disable events with account identity; the short-lived token CLI still prints
  only the resolved credential to stdout. The bridge's credential-change block
  and sanitized errors remain unchanged; real credentials were not accessed.
- Complete formula differs only in version and four binary hashes. Reviewed
  SHA-256: `9e6a172019ad0f9b2ab7089e3c43b21692dfb2f6fef23478ce6108ebcbbf8ba6`.
  No new formula lifecycle or execution behavior.
