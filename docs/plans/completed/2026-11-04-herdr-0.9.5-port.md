# Port Herdr customisations to 0.9.5

**Status:** Complete (installed and live-handed-off on 2026-11-04; visual check is the user's)
**Scope:** Herdr patch, pinned installer, Herdr operator docs, installed local binary, user-approved live handoff of the local server.

## Objective

Rebuild the patched Herdr from upstream v0.9.5 (latest as of 2026-11-04) with every
custom feature from the 0.9.1 patch, proven by a build-only run of
`install-herdr-focus`.

## Non-goals

- Stopping the server, or sending input to any agent pane.
- Changing keybindings, config, plugin behaviour or Pi/OMP integration.
- Adopting new upstream features beyond what the port needs.

## Decisions

- **Split guard vs new-pane sizing:** upstream 0.9.4 now sizes a new pane before
  spawning it (`new_pane_size`). The patch's "too small to read" guard runs first,
  in both the API split and plugin-pane paths, and still applies to zoomed plugin
  panes, as in 0.9.1.
- **Cell size for new-pane estimates:** the patch's `apply_pane_chrome` takes a
  cell size for pane gaps. Upstream's two new callers pass `app.host_cell_size`,
  the same state upstream uses for other new-pane sizing.
- **Pane fade:** kept inside the "runtime exists" branch; upstream's new
  restore-error branch follows it.
- **Tests:** adapted to multi-prefix (`&keybinds.prefix`) and the removed
  `ApiRequestMessage::stream_active` field.
- **Lint:** ran `cargo fmt` and fixed 4 mechanical clippy findings in patch code,
  so upstream's `cargo clippy --all-targets -- -D warnings` gate passes.
- **Known test failures:** 4 release-notes tests fail because the patch makes the
  default build label `dotfiles` instead of `stable`. Stock v0.9.5 built with
  `HERDR_BUILD_CHANNEL=dotfiles` fails the same 4; stock with the stable label passes.

## Risks and recovery

- Rollback: copy the 0.9.1 binary from the backup directory to `~/.local/bin/herdr`,
  then hand off to it (rehearsed above). Restoring the file alone does not change
  the running server. Reverting the repository change restores the 0.9.1 pin.
- Upstream 0.9.4 changed sidebar, Go To, prefix and key handling. Native and PTY
  tests cover the patch's features, but nobody has looked at 0.9.5 on screen yet.
- Unread markers lost in the handoff stay lost (Q-007); those conversations still
  hold their results.
